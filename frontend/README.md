# Frontend – Quản lý Phiếu đồng thuận

React + TypeScript + Ant Design (Vite). Hướng dẫn chạy, kiểm thử và triển khai xem [README ở thư mục gốc](../README.md).

| Lệnh | Mô tả |
|---|---|
| `npm run dev` | Chạy dev server tại http://localhost:5173 (proxy `/api`, `/health` tới API `http://localhost:5080`) |
| `npm run lint` | Kiểm tra mã nguồn bằng oxlint (cảnh báo bị coi là lỗi) |
| `npm run typecheck` | Kiểm tra kiểu TypeScript |
| `npm test` | Chạy unit test (Vitest + Testing Library) |
| `npm run build` | Build bản production vào `dist/` |
