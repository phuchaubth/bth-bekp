# BEKP Agent Instructions

Work incrementally.

For every assigned task:

1. Inspect the repository before changing files.
2. Write a short implementation plan.
3. Change only what is needed for the assigned issue.
4. Add or update automated tests.
5. Run all relevant build, lint, and test commands.
6. Do not introduce real hospital or patient data.
7. Do not weaken security to make tests pass.
8. Do not add unnecessary frameworks or dependencies.
9. Preserve Clean Architecture dependency rules.
10. Open a pull request and clearly document results.

If requirements are ambiguous, choose the simplest secure implementation that satisfies the acceptance criteria and document the assumption.
